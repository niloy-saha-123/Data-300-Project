# Data Directory

`data/raw/` holds original Kaggle JSON files. Leave them untouched.

`data/processed/` is fully generated by pipeline:

- `portfolio_clean.parquet`
- `profile_clean.parquet`
- `transcript_flat.parquet`
- `offer_response.parquet`
- `response_merged.parquet`
- `demographic_features.parquet`
- `behavioral_features.parquet`
- `offer_features.parquet`
- `features.parquet`
- `customer_segments.parquet`
- `uplift_features.parquet`

## Raw file notes

- `portfolio.json`: 10 offers, one JSON object per line.
- `profile.json`: 17,000 customers. Missing demographics use `age = 118`, `gender = null`, `income = null`.
- `transcript.json`: 306,534 event rows. `value` payload changes by event type.

## Transcript event counts

- `transaction`: 138,953
- `offer received`: 76,277
- `offer viewed`: 57,725
- `offer completed`: 33,579

## Target notes

- Classification target keeps only BOGO and discount receipts.
- Label is positive only when view happens before completion inside offer window.
- `offer_response.parquet` also tracks `completed_any` so no-view completions stay auditable.
